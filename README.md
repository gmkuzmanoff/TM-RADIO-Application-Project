# 🎧 TMRADIO Project  
Android Mobile Music & Radio Streaming Application

TMRADIO is a modern Android application designed for streaming high‑quality underground electronic music from TM‑Radio.com.  
The project focuses on simplicity, stability, and a smooth listening experience on mobile devices.

---

## 🚀 Features

- 📡 **Live Radio Streaming** – Listen to TM‑Radio’s electronic music stream and countless sessions.
- 🎵 **High‑Quality Audio Playback** – Stable playback with properly used Media Session.
- 📱 **Modern Android UI** – Clean user-flriendly interface built for Android 8+.
- 🔊 **Background Playback** – Music continues even when minimized and corresponding with bluetooth media devices.
- 📴 **Lock‑Screen Controls** – Play/Pause/Rewind/FastForward directly from notifications.
- ⚙️ **Lightweight & Fast** – Optimized for performance and low battery usage.

---

## 🛠️ Tech Stack

- **Language:** C#  
- **Framework:** Xamarin.Forms 5 (Cross‑Platform)  
- **IDE:** Visual Studio 2022  
- **Minimum Android Version:** API 26 (Android 8.0)  
- **Target Android Version:** Android 13+  
- **Streaming Protocol:** HTTP/ICY audio stream
